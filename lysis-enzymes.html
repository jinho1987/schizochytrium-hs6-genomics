01

Framing: a composition-vs-practice mismatch

Published Schizochytrium lysis protocols report success with cellulase, hemicellulase, lysozyme, and alkaline protease. But directly checking what this cell wall is actually built from complicates that picture.

What the wall is actually made of

Schizochytrium's wall is not chitin- or cellulose-based like a fungal wall. It's a Golgi-derived scale structure, ~21–36% carbohydrate (>95% L-galactose, a sulfated galactan) and ~30–43% protein/glycoprotein (Kazama & Kimura, Cell wall composition and synthesis via Golgi-directed scale formation in Schizochytrium aggregatum, Arch Microbiol). No cellulose, no chitin, no peptidoglycan — anywhere.

Yet the empirical lysis literature reports cellulase and hemicellulase as effective, and lysozyme and alkaline protease (commercially, Alcalase) are standard choices too (Cui et al., Optimization of Enzymatic Cell Disruption for Improving Lipid Extraction from Schizochytrium sp., PubMed 29367487; see also the Cell Walls of Lipid-Rich Microalgae review, MDPI 2311-5637/10/12/608). Of the four, only alkaline protease has an obvious mechanistic target (the wall's substantial protein fraction) — cellulase and lysozyme's canonical substrates simply aren't present. This page tests whether structure and docking evidence can distinguish "these enzymes happen to have promiscuous affinity for the real wall polymer" from "they work by some other route entirely."

The panel's organizing idea: identical function, different host

"Alcalase" is itself a useful example — commercially it's subtilisin Carlsberg from Bacillus licheniformis (UniProt P00780), but the same catalytic function has documented origins in B. subtilis and B. pumilus too. That became the template for the whole panel: wherever possible, each enzyme class is represented by the same function expressed in different host organisms, to see whether host origin shows up as a real structural/binding difference or is functionally silent.

04

Docking design

Each folded enzyme was docked (AutoDock Vina, via the vina/meeko python bindings) against two ligands: its own canonical substrate, and one shared probe representing the real wall polymer.

Canonical substrates
Suc-AAPF-pNA (protease), chitohexaose (lysozyme), cellopentaose (cellulase), xylopentaose (xylanase), neoagarohexaose (agarase) — all real PubChem-registered oligomers with established binding modes for their enzyme class.
The wall probe
A modeled sulfated L-galactan disaccharide, built to match the >95%-L-galactose composition reported for the real wall. No solved structure of the native Schizochytrium wall polysaccharide exists — this is an idealized approximation, not a literature-validated ligand.
Read before the results table — this is blind, exploratory docking

The search box covers the entire folded protein (no active-site residues were mapped for any of these 13 structures before docking), which Vina itself flagged during the run ("search space volume is greater than 27000 Å³... at low exhaustiveness, it may be impossible to utilize all CPUs"). Combined with exhaustiveness=8 (moderate, not exhaustive) and Vina's scoring function not being specialized for carbohydrate chemistry, absolute affinity values here should not be read as accurate binding free energies. They're treated as a relative, hypothesis-generating signal only — see evidence tiers.

What stands out

Cellulase is the surprise — near-parity with a substrate it "shouldn't" bind

O74706 (A. niger endoglucanase B) binds the modeled wall probe almost as well as cellopentaose itself (gap 0.24 kcal/mol) — despite the wall containing no cellulose. If this holds up under real (non-blind) docking, it's a candidate structural explanation for why cellulase empirically works on Schizochytrium: not because it recognizes cellulose that isn't there, but because it has promiscuous affinity for the sulfated galactan that is.

One reversal: subtilisin E binds the wall probe better than its own substrate

P04189 is the only enzyme in the panel where the galactan probe outscored the canonical ligand. A single data point from an unvalidated blind-docking setup shouldn't be over-read, but it's the most specific, falsifiable prediction this page makes — worth a focused (non-blind) re-dock before drawing any conclusion from it.

Xylanases and 3 of 4 proteases show the opposite pattern

Both xylanases and three of the four Alcalase-family proteases show the largest canonical-vs-probe gaps in the panel (>1 kcal/mol) — the least support here for a direct wall-polymer-binding mechanism. For the proteases this isn't a problem: the wall is 30–43% protein, so alkaline protease has an obvious real target regardless of what this probe ligand shows.

Host-origin variation, even among near-identical proteins

The four Alcalase-family proteases — nearly the same fold, broadly similar sequence identity — span a 2.2 kcal/mol range in canonical-substrate affinity (−6.36 to −8.60), with B. amyloliquefaciens subtilisin BPN' the strongest binder by a clear margin. Host origin is not functionally silent here, at least in this blind-docking approximation.

Evidence tiers & limitations

Consistent with the rest of this site: findings here sit at genuinely different confidence levels.

Reasonably solid

The wall-composition mismatch itself (L-galactan/protein wall vs. cellulase/lysozyme in the empirical lysis literature) — drawn directly from published compositional analysis, not this project's own modeling.

Exploratory / hypothesis-generating (most of this page)

Every docking affinity and gap above. Blind search box, moderate exhaustiveness, a scoring function not specialized for carbohydrates, and — for the galactan-probe ligand specifically — a modeled structure with no solved reference to validate against. Read comparisons (rankings, gaps) as more trustworthy than absolute kcal/mol values.

Single data points, not yet replicated

The subtilisin E reversal and the cellulase near-parity result are each based on one blind docking run against one ESMFold model. Both are concrete, falsifiable next steps (focused re-docking once an active site is identified) rather than settled findings.

Notes on this page

Structure prediction: local ESMFold (facebook/esmfold_v1 via HuggingFace transformers), single-sequence input, no MSA, GPU (originally RTX 3050; re-run on an RTX 5060 alongside the work described below, which is why fold times you'll see in the raw summary run faster than the table in section 03 implies for a 3050). Docking: AutoDock Vina via the vina python package, exhaustiveness=8, 9 poses per run, receptor prep via Open Babel (obabel, rigid), ligand prep via RDKit + Meeko. Sequences: UniProt reviewed (Swiss-Prot) entries only. Full pipeline is maintained alongside this project's other analysis code: fetch/fold/dock/render scripts in scripts/ (fetch_lysis_enzyme_sequences.sh, run_esmfold_lysis_panel.py, prep_lysis_ligands.py, dock_lysis_panel.py, render_lysis_structures.py, render_lysis_docking.py), all 13 sequences/structures and the 6 prepped ligands under results/lysis_enzymes/, raw Vina PDBQT poses and per-run logs under results/lysis_enzymes/docking/, the compiled affinities in results/lysis_enzymes/docking_results.json, and the rendered figures under figures/lysis_enzymes/.
